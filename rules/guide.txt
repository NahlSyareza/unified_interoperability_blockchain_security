Okay so here's the commands so far:
* TYPE <type> 
  Used to declare a type of something. Used for comparisons
  Planned usable <type>:
    - char
    - int
    - double
  
* GET <n>
  Used to get a sliced string based after n amounts of spaces. Can be improved to also detect another delimiter (i.e. semicolon, colon, comma, etc.)

* DELIM <delimiter>
  Define a delimiter to detect. Unimplemented

* SRC_UNIT <unit>

* TGT_UNIT <

* GET_FROM <key>
  Same as GET, but for non-raw syntaxes.

* CONV_TO <type>
  Used to convert a type. Base type is always strirng. Using in non-raw data syntaxes. Raw data syntax isn't affected. (see "On Network Type Data Retrieval")

* ASGN_TO <key>
  Used to assign a value to a key. Again this is used for non-raw data syntaxes. Perhaps I need to also have a command for a csv raw data syntax.

* IF <condition>
  Compare a value. Condition is always a string value for now

* ELSEIF <condition>
  It's an else if dawg

* THEN <value>
  If it's true, then update the value
  
* OTHERWISE <value>
  If it isn't then update the value
  
* OUT
  Used to convert a reg->input_data into reg->output_data. Mainly used to handle THEN and OTHERWISE

* APPEND_OUT
  Used to append reg->input_data into reg->output_data, uses reg->delimiter if multiple data is to be appended out.
